# HTML Login Page with Validation

Login page of the Job Vacancy Portal (TalentBridge Solutions) - the same login screen that is used in the final project.

- Username (Register / D.No): 4 to 30 letters or digits
- Password: date of birth in DD-MM-YYYY format
- A wrong value shows a message; correct values show "Login successful".

Try: username `25UCS553`, password `15-08-2005`.
